# Code of Conduct

Beyond Blue adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, welcome newcomers (this project exists to help students), give and accept constructive feedback gracefully, and keep discussions focused on what's best for the students we serve. Harassment, personal attacks and discriminatory language aren't tolerated.

## Reporting

Report unacceptable behaviour privately to the maintainer, Sampson ([@Yine-Eng](https://github.com/Yine-Eng)), through a [private security advisory](https://github.com/Yine-Eng/beyond-blue/security/advisories/new) or the contact details on the maintainer's GitHub profile. Reports are handled confidentially.
